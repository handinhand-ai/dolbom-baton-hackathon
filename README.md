# 돌봄바통 — 해커톤 시작본

발달장애인 긴급돌봄 상황에서 보호자가 확인한 돌봄 경험을 필요한 돌봄자에게 전달하는 서비스의 **개발 시작본**입니다.

## 현재 포함된 범위

- Node.js 22 기반 개발용 HTTP 서버 및 `GET /api/health`
- 한국어 기본 웹 화면과 공통 응답 스키마
- 기본 문법 검사 및 HTTP 테스트
- 개발 에이전트·GitHub 협업 안내와 작업 템플릿
- 서비스 기획 개요와 기술 스택 검토 문서

**기능 1·2·3 애플리케이션 구현은 이 시작본에 포함되지 않습니다.** 기능 명세는 구현을 지시하는 고정 출력이 아니라 요구사항이며, 실제 구현·계약·테스트 범위는 기능별 PR에서 검토합니다.

## 로컬 실행

Node.js 22 이상이 필요합니다. 이 시작본의 기본 서버는 외부 런타임 패키지가 필요하지 않습니다.

```powershell
npm run dev
```

브라우저에서 `http://127.0.0.1:3000`에 접속합니다. 종료는 `Ctrl+C`입니다.

## 인증·세션 API (A)

시연 계정 로그인·로그아웃, 로그인 상태 조회, 역할 확인 API(`/api/auth/*`)를 제공합니다. 세션은 HttpOnly 쿠키이고 저장소는 서버 메모리입니다. 경로·요청·응답 예시와 역할별 반환값은 [`docs/auth-api.md`](docs/auth-api.md)에서 확인합니다.

### 공통 화면 틀 (A)

`npm run dev` 후 <http://127.0.0.1:3000/a/>에서 로그인 → 역할별 시작 화면 → 하단 탭 틀을 확인합니다. UI 레퍼런스 v0.3(색·글자·버튼·알약 탭)과 Pretendard Variable(SIL OFL, `apps/web/public/a/fonts/`)을 적용했습니다. 시연 계정은 `guardian`, `caregiver`, `center`(비밀번호 `demo-1234`)이며 로그인 화면에서 역할을 고르면 채워집니다.

- 라우트: 보호자 `/g/home·manual·care·my`, 돌봄 선생님 `/c/home·manual·records·my`, 센터 관리자 `/c/center-admin`. 로그인하지 않았거나 역할이 다르면 `/login`·자기 홈으로 이동합니다(`access.js`).
- B·C·D는 `apps/web/public/a/screens.js`에서 자기 경로 한 줄만 교체해 화면을 끼웁니다. 아직 없는 화면은 자리표시 카드로 보입니다.
- 재사용: `a.css`(디자인 토큰·버튼·카드·탭), `icons.js`(선 아이콘), `access.js`(역할별 탭·접근 규칙), `api.js`(`getSession()` 등), `assets/minjun.png`(시연 캐릭터).
- 한계: 아이 맡기기·돌봄기록은 자리표시이고, D의 시연 화면(`/care`)은 아직 탭에 연결하지 않았습니다.

## 보호자 질문지 (B)

보호자로 로그인한 뒤 설명서 탭에서 Supabase의 활성 질문과 선택지를 불러옵니다. 답변은 로그인 세션의 `care_recipient_id`로 저장하며 재진입 시 복구합니다. 질문 조회와 답변 API, 데모용 DB 정책의 범위는 [`docs/questionnaire-api.md`](docs/questionnaire-api.md)에서 확인합니다.

## 검증

```powershell
npm run check
npm test
```

실행 여부와 결과는 별도로 기록합니다. 현재 사용자가 확인할 실제 테스트 결과가 없는 경우, 테스트가 통과했다고 가정하지 않습니다.

## 협업 원칙

모든 팀원과 팀장에게 `feature/* → Push → PR → 팀장 검토 → main`을 적용합니다. 세부 작업 하나당 독립 브랜치·PR을 만들고, 첫 유의미한 Push 직후 PR을 생성합니다. 미완료 작업은 Draft PR로 유지합니다. PR·CI 및 테스트 결과를 검토한 후 팀장이 최종 병합합니다. 이 규칙은 GitHub 권한 제어와 별개이며, 새 저장소에서 실제 보호 설정을 확인해야 합니다.

## 개인정보 및 AI

실제 돌봄 기록·음성·연락처·자격 증명은 이 시작본에 포함하지 않습니다. 시연에는 합성 데이터만 사용합니다. AI는 보호자가 확인한 사실과 공유 권한 범위 안에서 동작해야 하며, 의료 판단을 생성하지 않도록 별도 검증이 필요합니다.

## 배포

이 시작본은 해커톤 GitHub 저장소에서 관리합니다. 운영 배포는 아직 수행하지 않았으며, 배포 대상과 유료 API 사용은 별도의 검토·승인을 거쳐 결정합니다.

## 아이 맡기기 D 시연 기능

- `npm run dev` 실행 후 `http://127.0.0.1:3000/care`에서 보호자 신청, 센터 수락·종사자 배정, 종사자 배정 목록을 확인할 수 있습니다.
- 시연 데이터와 임시 `X-Demo-User` 헤더를 사용하는 메모리 저장소 기반 구현이며, 서버를 재시작하면 시연 상태가 초기화됩니다.
- `GET /api/care/access?care_recipient_id=`는 배정된 종사자의 현재 접근 가능 여부와 공유 카테고리를 반환합니다. `GET /api/care/assignments`는 본인 배정 목록을 반환합니다.
- 시연용 인증·초기화 경로는 운영용 인증과 접근 제어로 교체하기 전까지 공개 서비스에 배포하지 않습니다.
