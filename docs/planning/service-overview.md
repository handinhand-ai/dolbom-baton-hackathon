# 서비스 기획 개요

## 문제와 목표

보호자가 갑자기 돌봄을 맡길 때 평소 경험으로 익힌 의사소통 방식, 생활 습관, 불편 신호와 도움이 되었던 지원 방법이 충분히 인계되지 않을 수 있습니다. 보호자와 당사자의 의사를 존중하면서, 확인된 내용만 필요한 돌봄자에게 전달하는 것을 목표로 합니다.

## 사용자 역할

- **보호자:** 기록·검토·공유 범위 결정·새 정보 승인
- **돌봄 종사자:** 공유받은 항목 확인·상황별 질문·새 관찰 제안
- **당사자:** 선호와 의사가 돌봄 설명서에 반영되는 수혜자

## 기획된 핵심 기능 — 현재 시작본에는 구현되지 않음

1. **맞춤형 돌봄 설명서:** 한 번에 하나씩 묻는 질문지, 기록 확인과 빈 항목 보완, 선택적 공유
2. **한마디 기록:** 음성 또는 글 입력, 받아쓰기와 AI 구조화, 사람의 확인 후 저장, 종사자 기록과 일지 초안
3. **상황별 대응 안내:** 공유 항목 기반 한 장 카드, 근거·작성일을 동반하는 답변, 상충·기록 없음 표시, 보호자 승인 후 반영

## 비기능·보안 요구

- 입력값과 기록에 따라 결과가 동적으로 바뀌어야 하며 시연 데이터로 결과를 고정하지 않습니다.
- 근거가 부족하면 추정하지 않고 기록이 없음을 표시합니다.
- 보호자가 선택한 범위 밖의 돌봄 내용을 종사자에게 공개하지 않습니다.
- 실제 개인정보나 민감한 돌봄 정보 없이 합성 시연 데이터로 테스트합니다.
- 의료 판단을 대신하지 않으며, AI 출력은 근거와 권한을 검증합니다.

## 설계 변경 가능 범위

제안한 서비스의 문제 정의와 방향은 유지하되, 구현 과정에서 공공데이터 API 사용 여부와 ERD 등은 조정할 수 있습니다. 프롬프트 초안 준비와 합성 시연 데이터 준비는 가능하지만, **사용자에게 실제 도움이 되는 AI 기능 자체는 서비스에 포함되어야 합니다.** 기존 모델·API 활용도 후보입니다.

## 미확정 사항

카테고리 체계, 데이터 마이그레이션, 실제 외부 AI 모델·API 호출, 공유 보안, 개인정보 보존·삭제 정책, 배포 비용은 구현과 검증 전까지 확정 또는 운영 가능으로 표시하지 않습니다.
